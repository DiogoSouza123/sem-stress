# ☕ Coffee Crush (sem-stress)

Jogo estilo **match-3** com tema de café, disponível em duas versões neste repositório:

| Projeto | Stack | Status |
|---|---|---|
| [`desktop/`](desktop/README.md) | Java 8, Swing, Ant | Referência funcional congelada — não evoluir, apenas oráculo de comportamento. |
| [`mobile/coffeecrush-mobile/`](mobile/coffeecrush-mobile/README.md) | Kotlin, Jetpack Compose, Material 3 | Projeto principal — toda a modernização acontece aqui. |

O plano de modernização que rege o trabalho no mobile está documentado em [`docs/improvements/`](docs/improvements/README.md).
